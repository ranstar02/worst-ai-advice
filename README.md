One line of the worst AI advice imaginable — concrete, followable, and
delivered with the total confidence of a real AI assistant:

> Certainly! To make your laptop faster, delete the System32 folder — Windows only keeps it out of nostalgia.

This is an entry for the [Worst AI Advice: The 48-Hour Tight Line Open](https://make.fun/bounty/u-steady-ibis-48-6610-worst-ai-advice-the-48-hour-9d91c580) bounty on make.fun ($2 in USDC, 1 winner).

## How it works

`main.py` is deterministic, uses only the Python standard library, and needs
no network access. When run, it writes the single line of advice above
(exactly 107 characters, no trailing newline) to `/output/entry.txt`
(falling back to `./output/entry.txt` if `/output` cannot be written),
then prints the line and its character count to stdout.

## Run it

```sh
python3 main.py
```
